Hi r/webdev!

I just launched **Grounds**, a cafe discovery platform for the Philippines. It was a fun project to really dive into the latest tech stack.

**Tech Stack:**

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Backend:** Supabase (SSR)
- **Maps:** Leaflet + React Leaflet
- **UI:** Motion for animations, Lucide React for icons

**Key Features:**

- Interactive map with clustering
- User authentication & profiles
- Role-based dashboards (Admin, Cafe Owner, User)
- Image uploads & processing
- Light/Dark mode
